# Fotos de referência da JukeLinux original

Tiradas na VM (Linux Mint 22, 1024x768) com a JukeLinux original rodando como `jkb`, o pendrive-chave montado
**somente leitura** e uma pasta de músicas de teste (CDs do Jukebox Pix no formato `ARTISTA - CD`).
As teclas simuladas são as da placa (`interfaceteclado.txt`): CD+ seta para cima, CD- seta para baixo,
Música+ D, Música- seta para a direita, Ritmo R, Tocar Enter, Cancelar `*` numérico, Crédito U, Menu `/`
numérico.

Observações:
- Os avisos "Unable to create file //media/jkb/chave/..." aparecem porque a chave estava só para leitura: a
  original grava `creditos.txt` e `tocar.txt` no pendrive a cada crédito e a cada música.
- "Unable to open file .../ritmos/naotemjpgritmo.jpg": a original espera a pasta `ritmos/` (e `letras/`) com
  as imagens de cada ritmo, que não estava na cópia usada no teste.
- `14-menu.png`: menu do operador (relógios, % do ponto, valores, QR code e as abas Configurações, Relógios,
  Músicas, Interface e Outros).
